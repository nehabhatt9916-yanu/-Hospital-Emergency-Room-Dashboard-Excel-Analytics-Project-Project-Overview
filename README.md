# **🏥-Hospital-Emergency-Room-Dashboard-Excel-Analytics-Project-Project-Overview**
Interactive Hospital Emergency Room Dashboard built in Excel using Power Query, Power Pivot, and DAX to analyze patient flow, wait times, satisfaction scores, admissions, and departmental referrals for data-driven healthcare decision-making.


## 📌 Project Overview

This project presents an interactive **Hospital Emergency Room Dashboard** developed in **Microsoft Excel** to analyze emergency room operations and support data-driven decision-making.

The dashboard enables healthcare administrators to monitor patient visits, waiting times, satisfaction scores, admission trends, and departmental referrals through interactive visualizations and KPI cards.

---

## 🎯 Business Problem

Emergency departments experience high patient volumes and operational challenges every day.

Hospital management needs a centralized dashboard that can answer questions such as:

* How many patients visit the emergency room?
* Are patients being attended within the expected time?
* Which departments receive the highest referrals?
* Which age groups require the most medical attention?
* How satisfied are patients with the service?

This dashboard provides actionable insights that help improve operational efficiency and patient care.

# 📈 Key Insights

* Total Patients: **464**
* Average Wait Time: **35.19 Minutes**
* Average Satisfaction Score: **5.09 / 10**
* 61% of patients were attended within the expected time.
* Nearly 40% experienced delayed service.
* General Practice received the highest number of referrals.
* The 30–44 age group represented the largest patient segment.
* Admission and non-admission rates were nearly equal.
